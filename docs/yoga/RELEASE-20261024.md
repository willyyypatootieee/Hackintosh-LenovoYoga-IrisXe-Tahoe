# Lenovo Yoga — working Iris Xe acceleration, EFI and graphics WIP

I'm **[Willy Patootie (@willyyypatootieee)](https://github.com/willyyypatootieee)**.
I've confirmed Iris Xe acceleration on my Yoga 82UT. This release preserves my
working-stack files and separate development work. HDMI, cursor corruption,
GPU hangs and browser lag are still unresolved.

## Install: two downloads

1. **`Yoga-EFI-sanitized-20261024.tar.gz`** — matching Yoga EFI; add your own SMBIOS identity.
2. **`Yoga-GPU-installer-20261024.tar.gz`** — complete captured GPU payload,
   **repaired HookCase included**, and one **`Install GPU.command`** launcher.

Verify the matching `.sha256` files and follow the [installation guide](../../readme.md).
**No original/v2/v3 selection or separate repair is needed.** Those obsolete
downloads have been removed from this release; originals remain in my local backup.

The files come from my accelerated setup, but the consolidated installer has
**not been tested on a fresh macOS installation**. It retains the **25G241 +
original external-partition + non-internal disk** guards. A reformatted disk needs
target review; do not remove checks to force installation. EFI alone is not enough.

## Development backups — not additional install steps

- `Yoga-code-and-WIP-20261024.tar.gz` — source, EFI, documentation and isolated WIP.
- `Yoga-firmware-research-20261024.tar.gz` — reviewed ACPI/VBT/OpRegion; **never flash**.
- Each archive has its own `.sha256` file.
