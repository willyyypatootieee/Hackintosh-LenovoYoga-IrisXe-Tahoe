# Lenovo Yoga — working Iris Xe acceleration, EFI and graphics WIP

I'm **[Willy Patootie (@willyyypatootieee)](https://github.com/willyyypatootieee)**.
**I've confirmed working Iris Xe acceleration on my Lenovo Yoga 82UT.** This
release contains my active EFI, graphics installation files and separate WIP.
USB-C→HDMI, cursor corruption, GPU hangs and browser lag remain unresolved;
this is an experimental release, not a claim of complete stability.

Start with the [Yoga installation guide](../../readme.md). EFI alone is not the
complete graphics installation; use the matching GPU stack and repaired HookCase.

Huge thanks to **[JulioNectar's main project](https://github.com/JulioNectar/Hackintosh-XPS13Plus-IrisXe-Tahoe)**,
the foundation of this Yoga port, and to NootedGreen/HookCase and all upstream
contributors credited in the README.

## Assets

| Asset | Meaning |
|---|---|
| `Yoga-EFI-sanitized-20261024.tar.gz` | Active external Yoga EFI, with personal SMBIOS/Bluetooth identifiers cleared; add your own identity |
| `Yoga-code-and-WIP-20261024.tar.gz` | Source, documentation, EFI, reviewed firmware capture and isolated experimental snapshots |
| `Yoga-GPU-installer-original.tar.gz` | Original installer, historical/superseded; not the recommended baseline |
| `Yoga-GPU-installer-v2.tar.gz` | Existing native-signature GPU installer; v2 alone has the known HookCase link issue |
| `Yoga-HookCase-repair-v3.tar.gz` | Existing targeted HookCase repair, not a complete replacement for v2 |
| `Yoga-GPU-installed-capture-20261024.tar.gz` | Captured named GPU bundles + repaired HookCase; not a bootable OS image or new installer |
| `Yoga-firmware-research-20261024.tar.gz` | Reviewed ACPI/VBT/OpRegion subset; no raw DMI/MSDM/NVRAM/SPI image; never flash |
| `*.sha256` | SHA-256 checksum for the corresponding archive |

The original installer archives and installed-driver capture include modified
Apple GPU components; Apple's terms still apply. No macOS installation media is
provided. Do not assume the repository's source license licenses those binaries.

## Reinstall caveat

The installer scripts preserve their exact **25G241 + original external-partition**
guards. A newly formatted disk has a different identity; a refusal is intentional.
Do not remove guards or select an internal disk to force installation. Read
[recovery instructions](RECOVERY.md) before erasing anything. Download the assets
onto another disk and verify their checksums.

Public configuration is sanitized, so it is not byte-identical to the private
original config. Original EFI files were read from a read-only external mount;
this publication made no active-EFI or APFS changes. EFI hashes and enabled-file
paths passed offline checks. That is not a clean-install, monitor or stability test.
